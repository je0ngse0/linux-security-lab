# 리눅스 보안 실습실

리눅스 보안 점검 항목 20개를 가상 화면에서 체험하는 웹앱입니다. 설정을 바꾸고 같은 상황을 다시 실행해 조치 전후의 결과를 비교할 수 있습니다.

## 실행 방법

저장소를 내려받고 [dist/index.html](dist/index.html)을 브라우저에서 엽니다. 별도 설치나 빌드 없이 실행할 수 있습니다.

## 실습 방법

1. 왼쪽에서 실습할 취약점을 체크하고 **가상 서버 만들기**를 누릅니다.
2. **전체 점검**으로 현재 서버의 설정 상태를 확인하거나, 실습 항목을 골라 기본 설정으로 점검을 실행합니다.
3. 설정값을 바꾼 뒤 같은 점검을 실행해 결과를 비교합니다. **정상 작업 실행**으로 필요한 작업이 계속 가능한지 확인합니다.
4. 전체 점검을 다시 실행해 서버에 남은 미흡 항목을 확인합니다.

서버 한 대에 선택한 항목의 설정이 함께 유지됩니다. 항목마다 점검 절차와 조치 전후 결과를 볼 수 있습니다. 새 서버를 만들면 기존 설정과 결과가 초기화됩니다. 서버 상태는 현재 페이지에서 유지됩니다.

## 실습 항목

| 분류 | 항목 |
| --- | --- |
| 파일·디렉터리 | umask, 소유자·그룹이 존재하지 않는 파일, 시스템 주요 파일 권한, 홈 디렉터리 권한, Sticky Bit |
| 계정·인증 | 이전 비밀번호 재사용 제한, 로그인 실패 횟수 제한, 관리자 권한 위임 범위, 휴면 계정 |
| 예약 작업·프로세스 | cron 사용 계정 제한, 예약 작업 설정 파일 권한, 서비스 전용 계정 |
| 네트워크·원격 접속 | 서비스 접근 IP·포트 제한, 원격 터미널 유휴 타임아웃, SSH 관리자 직접 로그인 제한, 불필요한 리스닝 서비스 |
| 로그·운영 관리 | 로그 접근 통제, 로그 보존·회전, 관리자 작업 감사 기록, 시스템 시간 동기화 |

실습은 브라우저에서 가상 데이터로 진행됩니다. 각 판정은 해당 실습 시나리오의 기준을 따릅니다.

## 실제 리눅스 명령 실습

Docker와 Node.js가 설치된 로컬 환경에서 다음 명령으로 실행합니다.

```sh
node local/server.mjs
```

브라우저에서 [로컬 실습실](http://127.0.0.1:4781)을 열고 **실제 리눅스 셸 · 로컬 Docker**에서 컨테이너를 시작합니다. 처음 시작할 때 Alpine 이미지를 내려받을 수 있습니다.

```text
umask
touch before.txt
ls -l before.txt
umask 0027
touch after.txt
ls -l after.txt
```

컨테이너는 일반 사용자로 동작하고 네트워크 연결이 없으며, 실습 파일은 임시 디렉터리에 저장됩니다. `cd`, 변수, 파이프, 리디렉션은 같은 셸 세션에서 동작합니다. 명령줄을 한 줄씩 보내므로 전체 화면 편집기와 터미널 단축키는 지원 범위에서 제외됩니다. `exit`를 입력하면 실습 환경이 정리됩니다. 왼쪽에서 선택하는 20개 점검 시나리오는 기존 브라우저 실습에서 진행하고, 실제 터미널에서는 파일 생성과 권한 확인을 직접 체험할 수 있습니다.
